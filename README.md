# Open Core Lab

**Parallel computing for all.**

Open Core Lab turns the code examples from two university courses into step-by-step animations. Each step draws what
the program is doing (threads, MPI ranks, messages, memory, the GPU grid) and highlights the lines of source that
cause it. Click a highlighted line to jump to the step that explains it, and move between the picture and the code.

**Live site: https://buddhi1.github.io/opencorelab/**

## What it covers

- **PDC**: Parallel & Distributed Computing (Pthreads, OpenMP, OpenMP offload, MPI, CUDA, debugging)
- **HPML**: High-Performance Machine Learning (CUDA, deep neural networks, data-parallel training)

140 examples, 796 steps, 18 topics. The examples show the same files used in class, which live in
[buddhi1/pdc-class](https://github.com/buddhi1/pdc-class).

## Goals

- **See what the code does.** Parallel programs are hard to picture, so each example is drawn one step at a time.
- **Tie every picture to real code.** What you see is what you compile and run.
- **Learn at your own pace.** Step forward and back, replay or autoplay. Nothing to install: it runs in any modern
  browser, on a laptop or a phone.
- **Open to everyone.** The lab and its examples are free and open source, for students in the course and for anyone
  learning on their own.

## Feedback

Students can optionally share anonymous usage and feedback to help decide which examples to improve next. It is
entirely optional, and no names, emails or IP addresses are collected.
